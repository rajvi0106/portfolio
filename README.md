# Rajvi Singh Rathore — Portfolio
React + Vite. Theme: Nocturnal Cyber Artisan.

    npm install
    npm run dev      # local site at http://localhost:5173
    npm run build    # production files in /dist

Edit `src/data.js` to change projects, links and terminal text.
Deploy: push to GitHub and host the `dist` folder (Vercel, Netlify or GitHub Pages).
